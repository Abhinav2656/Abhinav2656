### 🛡️ Forged Systems
- **Mini-Redis Memory Core:** Engineered a bare-metal C++ LRU Cache managing raw Linux heap memory, bridged with a Python IPC, and deployed on AWS EC2.
- **AirMath:** Architected a gesture-controlled visual reasoning pipeline decoupling real-time OpenCV vision from a Flask backend, integrated with the Gemini API.
- **Medical Image GAN:** Developed an unpaired MRI to CT CycleGAN using PyTorch and MONAI for high structural fidelity in medical imaging.
- **AdSage:** Deployed a scalable GenAI retrieval system using FAISS and AWS Bedrock for automated content generation.
